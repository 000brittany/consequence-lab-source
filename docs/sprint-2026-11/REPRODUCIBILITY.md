# Sprint evidence and public snapshot reproducibility

This public appendix accompanies the [sprint report](REPORT.md) and
[executive summary](EXECUTIVE_SUMMARY.md). Their research evidence cutoff is
November 8, 2026. [Current source correspondence](../REPRODUCIBILITY.md),
[publication provenance](../../PUBLICATION_PROVENANCE.json) and
[fresh software validation](../../SNAPSHOT_VALIDATION.json) describe this
separate source publication.

The sprint synthesis distinguished autonomous observations, authored offline
controls and full Runner fixtures with synthetic model responses. Four paid
Rooms v3 run successes were independently confirmed from server metadata, while
their behavioral totals remained reported evidence. Mixed-horizon calibration
used authored policies, not autonomous models. No autonomous mixed result is
introduced by publishing this code.

The retained original v4 review records report 273 baseline tests passing with
provider/Inspect integrations required. New 188-call scheduling and 540-call
file-capacity reproductions underwent reconstruction, export and separate domain
checks. They do not recover the original lost executor bytes.

The final mixed calibration records report 924 complete traces and 1,542,253
source-replayed transitions; all cases receive separate day-end finance/capacity
checks, with two selected cases receiving 3,370 full independent transition checks.
These scopes are not a second independently written simulator over every record.

The pilot preparation fixture reports 190 decisions/1,630 events and 1,632
byte-equal reconstructed files, with 1,624 separate domain records. It uses mocked
Responses exchanges. An interrupted wrapper/finalization incident is retained
in the original record and described in the report; it is not proof of generic
paid crash recovery.
