# Synthetic experiment fixtures

The JSON files retained here are generated manifests, neutral instructions and
aggregate results of authored offline policies. They support exported regression
tests and document historical configuration. They are not raw paid-model
trajectories or a public release of private agent/API journals.

Several results belong to older source fingerprints. Tests deliberately preserve
that historical association rather than relabeling them as measurements from the
current snapshot. New test results appear separately in
[SNAPSHOT_VALIDATION.json](../SNAPSHOT_VALIDATION.json).

The original paid-launch READMEs, recovery handoffs and approval packets are
excluded. See [scientific status](../docs/SCIENTIFIC_STATUS.md) for the distinction
between autonomous observations and software/policy validation.
